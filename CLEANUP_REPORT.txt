WHITEBOARD BOTS - CODEBASE CLEANUP REPORT
Branch: webapp            Date: 2026-11-13            Baseline: commit 001198b

GOAL
  The web app is now the only workflow: every trajectory is generated,
  previewed and sent to the robot through it, over USB serial (or the
  "Simulated (no robot)" port, kept on purpose for testing without hardware).
  Everything that only served the old terminal CLI / matplotlib workflow was
  removed, along with unused helpers, dead parameters and duplicated code.

  Everything removed is recoverable from git history (commit 001198b).

RESULT
  Test suite: 92 passed in ~10 s, peak memory ~210 MB
  (before: ~2 min 10 s and ~13 GB peak, which got the terminal OOM-killed).
  Every file in the repo was reviewed; per-file details follow.

  Line counts are "baseline -> now". Some files grew because the branch also
  holds uncommitted feature work that was kept (ELLIPSE / bulge / mirrored
  entity support in DxfExtraction, the robot-linkage preview in pipeline,
  server and index.html), not because of this cleanup.


================================================================================
DELETED FILES
================================================================================

main.py  (303 lines)
  The interactive terminal CLI: robot/mode prompts, file pickers,
  "preselection" mode, matplotlib preview plot, comms selection and the
  post-run animation. Replaced entirely by the web app.

Plotter.py  (175 lines)
  matplotlib FuncAnimation of the robot (link lines, trace, manipulability
  heatmap, velocity ellipse). Only main.py used it; the web preview now draws
  and animates the linkage itself.

robots/ManipulabilityGrid.py  (43 lines)
  Board-space manipulability heatmap. Only Plotter.py used it.

paths/PointsIO.py  (19 lines)
  Saved the "_<name>_<n>.txt" points file. Only main.py used it.

paths/TrajectoryIO.py  (36 lines)
  Saved/loaded the per-robot trajectory .txt for the CLI's "run from saved
  TXT" mode. Only main.py used it. (The web app's "Download trajectory .txt"
  button still exports the same columns from the browser.)

comms/NetworkComms.py  (26 lines)
  TCP socket transport. Only main.py could select it; the web app talks to the
  robot over serial.

comms/PsuedoComms.py  (42 lines)
  Misspelled dry-run stub that printed commands and bypassed the ack
  protocol. Replaced by comms/SimulatedComms.py (see below).

tests/test_plotter.py  (43 lines), tests/test_manipulability_grid.py  (33 lines)
  Tests for the two deleted modules.

.TXTS/  (7 files, 4,609 lines)
  Generated CLI output (_gompei_*.txt, Spooler_gompei_*.txt,
  FiveBar_gompei_1000.txt) that had been committed. Nothing reads them now.


================================================================================
ADDED FILES
================================================================================

comms/SimulatedComms.py  (20 lines)
  Backs the web app's "Simulated (no robot)" port. Unlike PsuedoComms it goes
  through the real CommsBase.send_steps() protocol path: it "receives" each
  command and replies DONE after the move's real duration, so a simulated run
  behaves exactly like a serial one (timeouts included).
